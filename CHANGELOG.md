# История изменений

Формат: версия — дата — короткий список изменений. Полная история коммитов —
в git; этот файл описывает только заметные для пользователя изменения.

## [35.5.4] - 2026-10-28

- **Подтверждения больше не системные.** Вместо белого окна Windows вверху экрана
  появилось компактное окно в цветах приложения чуть ниже центра: Enter —
  подтвердить, Esc или клик мимо — отмена, у опасных действий кнопка красная.
  Окно заменяет все 16 прежних `confirm()`.
- **Сторож свободного места переехал в «Настройки»**, к токену и папкам: там же
  порог, кнопка включения и статус. На главной его больше нет, а в шапке окна
  появилась пилюля `🛡 50 ГБ` / `🛡 выкл` — состояние видно с любой вкладки.
- **«Сброс очереди» переехал в «Диагностику»**, рядом с пересозданием базы.
  Заодно исправлено: подписи кнопок больше не вылезают за правый край —
  название и счётчик стоят в две строки, кнопки переносятся по ширине.
- У пилюль в шапке появились описания при наведении: токен, куки, скорость,
  итоги сессий и сторож.
- Подсказка у поля потоков стала живой: «Выбрано: 10 · рекомендую 3 (ОЗУ 5.9 ГБ)»
  пересчитывается сразу при вводе, жёлтым — если выбрано больше рекомендации.
  Само поле честно подписано «Потоков (Безлимит)»: обычный Диск и сортировка
  подбирают число потоков сами по свободной памяти.

## [35.5.3] - 2026-10-28

- **Программа ставится и обновляется без прав администратора.** Установщик
  раскладывает её в `%LOCALAPPDATA%\Programs\YandexDiskBackup`, ярлыки и
  автозапуск создаются только для текущего пользователя, окно UAC не появляется.
  WebView2, если его нет, доустанавливается в профиль пользователя.
- Прежняя установка в `Program Files` больше не используется. Чтобы не осталось
  двух копий, старую версию надо один раз удалить вручную
  («Параметры → Приложения → Yandex.Disk Backup → Удалить») — установщик об этом
  предупреждает, а в самой программе висит баннер с путём старой папки.
  Базы, настройки и скачанные файлы в `%LOCALAPPDATA%\YandexDiskBackup`
  при удалении не затрагиваются.
- Самообновление тоже проходит без UAC. Пер-пользовательская установка
  распознаётся по реестру удаления, поэтому её больше не путают с portable-сборкой
  (раньше любая папка вне `Program Files` считалась portable и обновлялась ZIP-ом).

## [35.5.2] - 2026-10-28

- **Программа обновляется сама.** В «Диагностике» → «Обновления» появилась кнопка
  «Обновить до X.Y.Z»: установщик скачивается с GitHub с показом прогресса и
  сверяется по SHA-256, затем кнопка «Перезапустить и установить» закрывает
  программу, ставит новую версию и снова её открывает. Данные, настройки и
  скачанные файлы не затрагиваются. Раньше кнопка только открывала страницу релиза.
- Windows запросит подтверждение администратора — приложение установлено в
  Program Files. Обновление portable-сборки распаковывает ZIP поверх папки.
- В релиз добавляются файлы `.sha256` для установщика и portable ZIP: без
  совпадения контрольной суммы скачанный файл не запускается.
- «Резервные копии баз»: все три кнопки копий теперь одинаковые (раньше «Общая
  копия» была единственной синей и выглядела как единственно доступная). Перед
  созданием копии программа спрашивает подтверждение, а на время создания
  кнопки блокируются.
- Кнопка «Сформировать базу данных» переименована в **«Обновить список файлов»**
  с подписью «Обходит облако и добавляет новые файлы. Ничего не скачивает».
- Журнал «Выполнение процесса» больше не возвращается в конец, если его
  прокрутили вверх: автопрокрутка работает только когда пользователь сам внизу.
  Журнал листается клавиатурой, а история увеличена с 25 до 200 строк на задачу
  (для полного цикла — 300), после перезагрузки страницы — до 300 строк.

## [35.5.1] - 2026-10-27

- Кнопка **«Скачать всё» стала полным циклом**: сначала проверяет облако на
  новые файлы (scan Диска и collect Безлимита), затем скачивает новые и
  докачивает сбойные — ошибки Диска (failed) и пропущенные Безлимита (skipped).
  Раньше новые файлы не искались вовсе, а повтор сбойных срабатывал один раз.
- Сбойные файлы повторяются до **3 проходов** с паузой 60 секунд. Если за проход
  не удалось скачать ни одного сбойного, проходы прекращаются досрочно. Число
  проходов можно изменить в поле «Проходов по сбойным» (1–5).
- Галочка «Сначала новые, затем сбойные» убрана: это поведение теперь всегда
  включено. Для быстрого прогона только новых файлов остаётся пошаговый режим.
- **Итоговое окно после скачивания**: отдельно по Диску и Безлимиту показано,
  сколько скачано, сколько осталось сбойных и объём. Сводка также остаётся в
  карточке процесса, а не затирается логом последней задачи (раньше результаты
  Диска исчезали, как только Безлимит завершался позже).
- Бейджи сессии теперь показывают и число ошибок, а не только успешные файлы.
- Исправлено: счётчик Безлимита больше не обнуляется в конце запуска — число
  скачанных файлов остаётся в бейдже (раньше показывалось `0`).
- Исправлено: код возврата 1 от Диска (часть файлов не скачалась из-за HTTP 500)
  больше не показывается как «Ошибка» или «Остановлено пользователем» — вместо
  этого видно «Завершено с ошибками (N файлов)».

## [35.5.0] - 2026-10-27

- В «Диагностике» появились **резервные копии баз**: отдельно для Диска,
  отдельно для Безлимита и общая копия обоих в одном ZIP. В копию попадают
  только статусы, ошибки и пути — сами файлы не читаются, поэтому отключённые
  диски и другие буквы не мешают.
- Копии можно **восстановить прямо из программы**. Перед заменой текущая база
  автоматически сохраняется, так что восстановление обратимо. Показаны дата,
  версия программы и число скачанных/пропущенных файлов; кнопка включается
  только после ввода слова `ВОССТАНОВИТЬ`.
- Восстановление заменяет только записи о статусах: файлы на дисках не
  удаляются и не проверяются. Всё, что скачано после даты копии, снова станет
  «в очереди»; разложенные сортировкой файлы будут скачаны заново.
- Старые автоматические копии от обновления схемы (`*.bak_v…`) тоже видны в
  списке и доступны для восстановления.
- Пересоздание базы Безлимита теперь доступно на вкладке «Диагностика» с
  автоматической копией и подтверждением словом `ПЕРЕСОЗДАТЬ`.

## [35.4.9] - 2026-10-27

- Панель запуска разделена на два понятных блока: «Быстрый запуск: скачать всё»
  (1 клик, Диск + Безлимит) и «Пошаговый режим» (только выбранный раздел).
  Раньше они выглядели как одна общая настройка.
- Под каждой кнопкой запуска добавлена короткая подсказка: что делает
  «Сформировать базу данных», «Запустить скачивание», «Остановить» и
  «Скачать всё».
- Галочка «Сначала новые, затем сбойные» теперь явно объясняет, что повторяет
  ошибки Диска (failed) и пропущенные файлы Безлимита (skipped).
- У галочки «Разложить фото/видео по датам» появилось предупреждение: сортировка
  может занять много времени, её можно отложить и сделать позже на вкладке
  «Организация». В быстром запуске для неё добавлен отдельный переключатель.
- «Сформировать базу данных» для Безлимита теперь не пересоздаёт базу, а
  дополняет её новыми файлами из облака. Статусы уже скачанных и пропущенных
  файлов сохраняются, повторное скачивание не запускается.
- Полное пересоздание базы Безлимита больше не предлагается в обычном окне: оно
  доступно только на вкладке «Диагностика» отдельным блоком, с автоматической
  копией базы, счётчиками последствий, предупреждением о повторной загрузке
  после сортировки и подтверждением словом `ПЕРЕСОЗДАТЬ`. Команда
  `--scan-only --force` по-прежнему работает в консоли.
- Исправлено: галочка повтора у Диска теперь поднимает старые failed-файлы,
  даже если в текущем проходе новых ошибок не было. Раньше при пустой очереди
  новых файлов повтор не запускался, хотя сбойные файлы в базе оставались.

## [35.4.8] - 2026-10-27

- В «Организации» кнопка «Остановить» больше не выглядит активной, когда
  сортировка не запущена: до старта она неактивна и снова гаснет после
  завершения. Раньше она была красной всегда и создавала впечатление
  работающего процесса.

## [35.4.7] - 2026-10-27

- В полях ввода снова работает правая кнопка мыши: «Копировать», «Вставить»,
  «Выделить всё». Раньше вставлять можно было только через Ctrl+V.
- README переписан под нового пользователя: сначала готовый установщик и portable
  ZIP, Python — только для запуска из исходников.
- Исправлены названия вкладок и кнопок: «Главная», «Настройки», «Организация»,
  «Диагностика», «Сформировать базу данных», «Запустить скачивание»,
  «Применить сортировку».
- В окне первого запуска и на вкладке «Диагностика» добавлена подсказка:
  «ключ выдаёт ex3544; без него отчёт остаётся на диске».
- Формулировка «Соавтор» заменена на «Автор доработок и мейнтейнер».
- Добавлен CHANGELOG.md; текст релиза теперь берётся из этого файла.
- Уточнено, что ключ отправки отчётов — общий секрет Cloudflare Worker, а не
  ключ Яндекса; публичная сборка его не содержит.
- Раздел «Требования» разделён на готовую сборку и запуск из исходников.
- Исправлены неточности: MSS clamp работает не на всех ОС, дедупликация в базе
  идёт по MD5, а SHA-256 используется при сортировке; убрана устаревшая кнопка
  «Очистить и заново».
