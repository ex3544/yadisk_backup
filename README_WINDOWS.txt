=====================================================================
    YANDEX.DISK BACKUP — ИНСТРУКЦИЯ ДЛЯ WINDOWS
=====================================================================

0. ОБЫЧНОМУ ПОЛЬЗОВАТЕЛЮ PYTHON НЕ НУЖЕН:
   • Скачайте готовый установщик или portable ZIP со страницы релизов:
     https://github.com/ex3544/yadisk_backup/releases
   • Установщик сам ставит программу в Program Files и при необходимости
     доустанавливает WebView2. Python не требуется.
   • Всё, что ниже (пункты 1–2), нужно только для запуска из исходников.

1. ЗАПУСК ИЗ ИСХОДНИКОВ / СБОРКА EXE:
   • Запустите файл «setup_wizard.bat» (двойной клик мышью).
   • Интерактивный мастер проверит наличие Python, при необходимости
     предложит установить Python/pip и нужные библиотеки.
   • Затем мастер спросит, собрать ли автономный файл «YandexDiskBackup.exe».
   • После сборки exe лежит в папке «dist\YandexDiskBackup\YandexDiskBackup.exe»
     и его можно запускать на любом компьютере даже БЕЗ установленного Python.

2. ЕСЛИ PYTHON УЖЕ УСТАНОВЛЕН:
   • Для быстрой сборки .exe запустите «build.bat».
   • Для запуска Web-интерфейса напрямую запустите «webui.bat».
   • «setup.bat» — упрощённая установка зависимостей без мастера.

2a. ЕСЛИ ЧАСТЬ ФАЙЛОВ НЕ СКАЧИВАЕТСЯ:
   • Ошибки «HTTP 500», «Read timed out», «IncompleteRead» означают
     недоступные серверы хранения Яндекса, а не сбой программы.
   • Такие файлы помечаются failed/skipped и докачиваются позже:
       python main.py retry-failed
       python unlim_backup.py --target skipped --media all --out-dir "C:\Unlim"
   • Список недоступных файлов: python report_status.py
     (результат в logs\download_report.md)

3. ГДЕ БРАТЬ ТОКЕН И КУКИ:
   • Токен Яндекс.Диска: https://yandex.ru/dev/disk/poligon/
     (нажмите «Получить OAuth-токен» и скопируйте в WebUI или .env).
   • Cookies для Безлимита: установите расширение «Cookie-Editor» в браузере,
     откройте https://disk.yandex.ru, нажмите «Export» -> «Export as JSON»
     и вставьте в WebUI во вкладку «Безлимит».
