# 📁 Руководство: organizer.py (Sergey Pukhir, ex3544)

Автономный кроссплатформенный органайзер файлов и медиа с автоматической сортировкой по датам, категориям и детекцией дубликатов на основе SHA-256.

---

## 🌟 Возможности и структура раскладки

Скрипт раскладывает свалку скачанных файлов по понятной и удобной структуре:

1. 📷 **`Фото/`** — сортируются по подпапкам `Год/Месяц/` (например, `Фото/2026/10/`). Дата определяется автоматически по имени файла (`YYYY-MM-DD`, `IMG_YYYYMMDD`) либо по системному времени создания.
2. 🎥 **`Видео/`** — сортируются по подпапкам `Год/Месяц/` (например, `Видео/2026/10/`).
3. 📄 **`Документы/`** — офисные файлы, таблицы, тексты, книги (`.pdf`, `.docx`, `.xlsx`, `.txt`, `.csv`...).
4. 📦 **`Архивы/`** — архивы и образы дисков (`.zip`, `.rar`, `.7z`, `.tar`, `.gz`, `.iso`...).
5. 💻 **`Программы/`** — исполняемые файлы и дистрибутивы (`.exe`, `.msi`, `.deb`, `.apk`, `.iso`...).
6. 🎵 **`Аудио/`** — музыка и голосовые записи (`.mp3`, `.wav`, `.flac`, `.m4a`...).
7. 📁 **`Прочее/`** — все остальные типы файлов.
8. 👥 **`duplicates/`** — папка изоляции дубликатов.

---

## 🔍 Интеллектуальный поиск дубликатов (3-уровневая проверка)

Чтобы моментально обрабатывать десятки тысяч файлов без лишней нагрузки на диск, реализован 3-уровневый алгоритм:
1. **Сверка размера файла:** файлы с уникальным размером физически не могут быть дубликатами (диск для них даже не читается повторно).
2. **Быстрый хэш (64 КБ):** если размеры совпадают, считывается только первый блок файла.
3. **Полный хэш SHA-256:** если первые блоки совпали, вычисляется полный SHA-256 для 100% гарантии идентичности.
4. Найденный дубликат безопасно перемещается в подпапку `duplicates/` (без затирания исходника).

## 🖥️ Два режима работы

### Вариант 1: Встроенный Веб-Интерфейс «Все в одном окне»
Запустите скрипт без аргументов или с флагом `--web`:
```bash
python organizer.py --web --port 8002
```
Откройте в браузере: **`http://127.0.0.1:8002`** (или по сети/Tailscale).

**В веб-панели доступно:**
- Выбор папки с файлами (Откуда) и целевой папки (Куда).
- Переключение режима: «Переместить» (быстро, освобождает диск) или «Скопировать».
- Чекбокс **Dry-Run (Тестовый запуск)** для безопасной проверки структуры без изменения файлов на диске.
- Прогресс-бар, счётчики по каждой категории в реальном времени.
- Интерактивный лог перемещения файлов.

---

### Вариант 2: Консольный запуск (CLI)

#### 1. Тестовый прогон без изменения файлов (Dry-Run):
```bash
python organizer.py --src "/media/vb/backup Ya1/Unlim" --dst "/media/vb/backup Ya1/Sorted" --dry-run
```

#### 2. Боевая раскладка с перемещением файлов:
```bash
python organizer.py --src "/media/vb/backup Ya1/Unlim" --dst "/media/vb/backup Ya1/Sorted" --action move
```

#### 3. Безопасная раскладка с копированием (сохранить исходники):
```bash
python organizer.py --src "/media/vb/backup Ya1/Unlim" --dst "/media/vb/backup Ya1/Sorted" --action copy
```

## 📋 Таблица параметров CLI

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--src` | — | Папка с файлами для сортировки |
| `--dst` | — | Папка назначения |
| `--action` | `move` | Действие: `move` (переместить) или `copy` (скопировать) |
| `--dry-run` | `False` | Тестовый запуск без изменения файлов на диске |
| `--web` | `False` | Запуск веб-дашборда (активируется автоматически при отсутствии `--src`/`--dst`) |
| `--port` | `8002` | Порт веб-интерфейса |
| `--host` | `0.0.0.0` | Сетевой интерфейс для веб-сервера |

> **Windows:** примеры выше используют Linux-пути. На Windows указывайте пути в кавычках, например:
> ```bat
> python organizer.py --src "D:\Unlim" --dst "C:\Sorted" --dry-run
> ```
> Длинные и нестандартные пути поддерживаются (внутри используется префикс `\\?\`).
