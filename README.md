# Yandex.Disk Backup — массовое скачивание всего диска и безлимитного фото-хранилища

> **Готовый инструмент для миграции с Яндекс.Диска.** Скачивает обычные файлы через официальный REST API и скрытый безлимит (Photoslice — фото с телефонов) через куки браузера. Дедупликация по MD5, сортировка по полочкам, веб-интерфейс. Запуск одним кликом — зависимости ставятся сами.

![Python](https://img.shields.io/badge/Python-3.10+-blue) ![FastAPI](https://img.shields.io/badge/FastAPI-0.115+-009688) ![License](https://img.shields.io/badge/license-MIT-green) ![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)

**Ключевые сценарии:**
скачать всё с Яндекс.Диска · скачать безлимит Яндекс.Фото · бэкап перед отменой подписки · миграция с Yandex Disk на Google Drive / OneDrive / локальный NAS · экспорт фото с телефона из Яндекс.Диска · download Yandex.Disk Photoslice · Yandex Disk full backup tool

## Что умеет

| Возможность | Как работает |
|---|---|
| 💾 **Скачивание обычного диска** | Через официальный REST API Яндекс.Диска в естественном порядке (`rowid ASC`). Нужен OAuth-токен. Авто-защита от сетевых зависаний (IPv4, MSS clamp) |
| 📸 **Скачивание безлимита** | Скрытое мобильное фото-хранилище (Photoslice) напрямую с CDN серверов Яндекса на полной скорости канала (`unlim_backup.py by PUH`) |
| 🗂 **Сортировка по полочкам** | Раскладывает файлы по типам: Фото/Видео/Документы/Архивы/… с подпапками по годам и месяцам (`organizer.py`) |
| 📁 **Выбор папок через Проводник** | Нажатие кнопки «Обзор» открывает системное окно выбора папки ОС (Windows Explorer / Zenity / KDialog / Tkinter) |
| 🧹 **Дедупликация** | По MD5 и SHA-256 — одну и ту же фотку в разных папках оставляет один раз |
| 🔄 **Resume** | Прерванное скачивание возобновляется с того же места. Хранит состояние в SQLite (`state.db` и `unlim_state.db`) |
| 🌐 **Веб-интерфейс** | Тёмная тема в стиле Apple на `http://localhost:8000`, live-баннеры статуса баз, счётчики файлов и живой лог |
| ⚡ **Параллельность** | Число потоков подбирается автоматически по объёму ОЗУ (`auto_workers()`: 1 при ≤4 ГБ, 3 при ≤6 ГБ, 4 при большем). Можно задать вручную: для обычного диска 4–5 (больше → 429), для безлимита до 24 |
| 🛡 **Безопасность** | CSRF-защита, валидация путей, маскировка токена, atomic-write для куки |
| 🚀 **One-click запуск** | Запуск любого скрипта без параметров (`webui.bat`, `./webui.sh`, `python main.py`, `python unlim_backup.py`) сразу поднимает дашборд |

## Установка (1 минута)

### Шаг 1 — Установи Python (один раз, если ещё не стоит)

Скачай Python 3.10+ с [python.org/downloads](https://www.python.org/downloads/).
**При установке отметь галочку «Add Python to PATH»** — это важно!

### Шаг 2 — Скачай проект

```bash
git clone https://github.com/ex3544/yadisk_backup.git
```

Или просто скачай ZIP с GitHub (зелёная кнопка `Code → Download ZIP`) и распакуй.

### Шаг 3 — Запусти

**Windows:** двойной клик по **`webui.bat`**

**Linux / macOS:**
```bash
bash webui.sh
```

**Всё. Больше ничего делать не надо.**

При первом запуске скрипт:
1. Проверит установлен ли Python
2. Проверит версию (нужна 3.10+)
3. Проверит `pip` — если нет, доставит
4. Установит все библиотеки из `requirements.txt` (~1 минута)
5. Запустит сервер
6. Откроет браузер автоматически на `http://localhost:8000`

При следующих запусках всё это пропускается — сразу запуск сервера.

### Где хранятся данные

Программа и изменяемые данные разделены (см. `paths.py`):

- при запуске из исходников, если рядом уже есть `.env`/`state.db`/`cookies.json`, всё остаётся в папке проекта — текущая установка продолжает работать как раньше;
- в собранной версии данные лежат в `%LOCALAPPDATA%\YandexDiskBackup` (базы, `.env`, куки, логи, отчёты);
- перенести состояние в другое место можно переменной `YADISK_DATA_DIR`.

Перед обновлением схемы БД автоматически создаётся резервная копия `*.db.bak_v<версия>_<дата>`.

### Первый запуск и диагностика

На чистой установке при первом открытии появляется окно настройки: OAuth-токен,
папка для обычного Диска и папка для Безлимита. Кнопка «Позже» закрывает окно —
всё это можно указать на вкладке «Настройки». Куки для Безлимита не обязательны
на первом шаге.

На вкладке **«Диагностика»** есть две кнопки:

- **«Собрать отчёт»** — сохраняет ZIP в `reports/` внутри папки данных и
  показывает краткую сводку прямо в интерфейсе;
- **«Отправить отчёт»** — отправляет этот ZIP через Cloudflare Worker в Telegram.

В отчёт входят версия программы, сведения о системе и памяти, пути, настройки
без секретов, размеры и статусы баз, статусы задач, последние строки логов и
найденные ошибки. **Токен, куки, содержимое файлов и полные базы в отчёт не
попадают** — все строки дополнительно проходят редактирование секретов.

Если ключ отправки не задан, отчёт всё равно собирается и остаётся на диске.
Ключ можно сохранить на вкладке «Диагностика»; он хранится локально в
`DATA_DIR\.report_key.txt` и в отчёт не включается.

### Оконный режим и трей

Начиная с этапа 3 приложение можно запускать как обычную программу:

```bash
python launcher.py
```

- открывается отдельное окно с дашбордом (Edge WebView2), без вкладки браузера;
- в системном трее появляется значок: «Открыть окно», «Открыть в браузере»,
  «Папка данных», «Выход»;
- закрытие окна **сворачивает приложение в трей**, задачи продолжают работать;
- полный выход — только через пункт «Выход» в трее.

Сервер слушает `127.0.0.1` (наружу не открыт). Если порт 8000 занят, берётся
следующий свободный; если приложение уже запущено, второе окно не создаётся —
открывается браузер с уже работающим экземпляром. Переопределить адрес/порт
можно переменными `WEBUI_HOST` и `WEBUI_PORT`. Если WebView2 недоступен,
приложение открывается в браузере, а трей остаётся рабочим.

Для оконного режима нужны `pywebview`, `pystray` и `Pillow` (они уже в
`requirements.txt`). Собранная версия запускается тем же `launcher.py` через
`YandexDiskBackup.exe`.

## Использование

### Вариант 1: один клик «Запустить» (рекомендую)

1. Открой вкладку **«Настройка»**:
   - Получи OAuth-токен на [yandex.ru/dev/disk/poligon](https://yandex.ru/dev/disk/poligon/) → жми «Проверить» → «Сохранить»
   - Укажи папку куда скачивать (например `D:/YandexBackup`) — **не указывай корень диска!**
   - Опционально: вставь cookies браузера для безлимита
2. Открой вкладку **«Главная»** → нажми **«Запустить»**
3. Программа сама всё сделает по очереди: scan → download → collect → workers

### Вариант 2: пошагово с выбором типов файлов

1. Вкладка **«Диск»** → **«Проверить диск»**
2. Когда сканирование закончится — появится список:
   ```
   📸 Фото        4 200 файлов  25 ГБ   [⬤]
   🎬 Видео         900 файлов  40 ГБ   [⬤]
   📄 Документы    200 файлов   1 ГБ    [ ]
   📦 Архивы        30 файлов   500 МБ  [ ]
   ⚙ Программы     50 файлов   80 МБ   [ ]
   ```
3. Переключатели — выбери что хочешь скачать (фото и видео включены по умолчанию)
4. **«Скачать выбранное»** — поедет

### Безлимит (фото с телефона)

Яндекс прячет фото с мобильных приложений в скрытом хранилище. Через REST API оно не отдаётся, но можно достать через куки браузера:

1. Установи расширение [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm)
2. Зайди на [disk.yandex.ru](https://disk.yandex.ru/client/disk), залогинься
3. Кликни иконку Cookie-Editor → **Export → Export as JSON**
4. В UI на вкладке **«Настройка»** в поле «Cookies» вставь JSON → **«Проверить»** → **«Сохранить»**
5. Вкладка **«Безлимит»** → **«Собрать список»** → **«Скачать выбранное»**

### Сортировка скачанного

Когда всё скачал — можешь автоматически разложить по полочкам:

1. Вкладка **«Сортировка»** → укажи папку с файлами
2. **«Только отчёт»** — увидишь сколько чего и сколько дубликатов
3. **«Применить»** — раскладывает в структуру:
   ```
   Папка/
   ├── Фото/2024/2024-08/...
   ├── Видео/2023/2023-07/...
   ├── Документы/
   ├── Архивы/
   ├── Программы/
   ├── Аудио/
   ├── Прочее/
   └── _duplicates/  ← дубликаты сюда (можешь потом удалить)
   ```

## CLI (если UI не нужен)

```bash
# Обычный диск
python main.py check                    # проверить токен
python main.py scan                     # построить карту диска
python main.py download --workers 4     # скачать всё
python main.py retry-failed             # повторить упавшие
python main.py verify                   # проверить MD5
python main.py stats                    # статистика

# Безлимит (нужен cookies.json)
python unlim_backup.py --scan-only                      # собрать список фото/видео
python unlim_backup.py --target pending --media all \
    --out-dir "D:/Unlim" --workers 4                    # скачать новые
python unlim_backup.py --target skipped --media all \
    --out-dir "D:/Unlim" --workers 4                    # повторный проход по сбойным
python unlim_backup.py --target all --media all \
    --out-dir "D:/Unlim" --workers 4                    # pending, затем один проход skipped
# без параметров — сразу открывает WebUI

# Сортировка
python organize.py --input "D:/Backup"                  # отчёт
python organize.py --input "D:/Backup" --action move    # применить
```

## Сборка установщика (Windows)

1. Поставьте зависимости сборки:

   ```bash
   python -m pip install -r requirements.txt "pyinstaller>=6.0"
   ```

2. Соберите приложение (onedir):

   ```bash
   python build_exe.py
   # результат: dist\YandexDiskBackup\YandexDiskBackup.exe
   ```

3. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php) и соберите установщик:

   ```bash
   python build_installer.py
   # результат: installer_output\YandexDiskBackup-35.4.4-setup.exe
   ```

Установщик ставит программу в `Program Files` (нужны права администратора),
создаёт ярлыки и, по желанию, автозапуск. Данные (базы, `.env`, куки, логи)
остаются в `%LOCALAPPDATA%\YandexDiskBackup` и **не удаляются при удалении
программы**.

Ключ отправки диагностических отчётов можно встроить в установщик: положите
его в локальный `.report_key.txt` или переменную `REPORT_KEY` перед сборкой.
Ключ не попадает в репозиторий и не выводится в консоль. Сборка без ключа:
`python build_installer.py --no-key` — тогда ключ вводится вручную на вкладке
«Диагностика».

Если WebView2 Runtime на компьютере нет, установщик сам запустит официальный
Microsoft Edge WebView2 Bootstrapper (нужен интернет). Если установить не
удалось, приложение всё равно запустится и откроется в браузере. Загрузчик
скачивается при сборке установщика с сайта Microsoft и проверяется по
цифровой подписи; в git он не попадает.

4. По желанию — переносимый ZIP без установки:

   ```bash
   python build_portable.py
   # результат: dist\YandexDiskBackup-35.4.4-portable.zip
   ```

   Архив распаковывается в папку `YandexDiskBackup` и запускается двойным
   кликом по `YandexDiskBackup.exe`. Рабочие данные и секреты в него не
   включаются; при первом запуске создаётся чистая папка данных.

## Обновления

- Готовые сборки лежат в разделе
  [Releases](https://github.com/ex3544/yadisk_backup/releases): установщик и
  portable ZIP. CI собирает их автоматически по тегу `v*`.
- В приложении: **«Диагностика» → «Обновления» → «Проверить обновления»**.
  Программа сравнивает свою версию с последним релизом и даёт ссылку на
  скачивание. Автоматически ничего не скачивается и не запускается.
- Публичные сборки **не содержат ключ отправки отчётов**. Свой ключ вводится
  на вкладке «Диагностика» → «Ключ отправки» и хранится только на компьютере.
- Чтобы выпустить обновление: поднимите `APP_VERSION` в `version.py`,
  закоммитьте, поставьте тег `v<версия>` и запушьте его. GitHub Actions соберёт
  установщик и опубликует Release. При обновлении базы, настройки и куки в
  `%LOCALAPPDATA%\YandexDiskBackup` сохраняются.

## Часто задаваемые вопросы

### Запустил `webui.bat`, а он говорит «Python is not installed»

Установи Python с [python.org/downloads](https://www.python.org/downloads/) и **обязательно** отметь галочку «Add Python to PATH» при установке. После этого закрой все cmd-окна и запусти `webui.bat` снова.

### Установка зависимостей зависла

Проверь интернет. Если медленный — `pip install -r requirements.txt` может занять до 5 минут.

### При запуске пишет «Failed to install dependencies»

Скорее всего pip не имеет доступа в интернет (фаервол / прокси). Попробуй вручную:
```bash
pip install -r requirements.txt
```
Если ошибка повторится — скриншот в issue на GitHub.

### Сервер запустился но браузер не открылся

Открой вручную: http://localhost:8000

### Скачивание прерывается

- **БД сохраняет прогресс** на каждом файле — просто запусти скачивание снова, оно продолжит
- Если совсем застряло — нажми кнопку **«Очистить и заново»** в карточке «Что нашлось»

### Токен перестал работать

OAuth-токен Яндекса живёт примерно год. Получи новый на [yandex.ru/dev/disk/poligon](https://yandex.ru/dev/disk/poligon/) и сохрани через UI (кнопка «Удалить» рядом со старым → вставь новый).

### Cookies перестали работать (для безлимита)

Сессионные куки браузера живут несколько часов / дней. Зайди в браузере на disk.yandex.ru заново, экспортируй cookies снова через Cookie-Editor и обнови в UI.

### Файлы падают с `HTTP 500`, `Read timed out`, `IncompleteRead`

Это не баг программы, а **сгоревшие/недоступные серверы хранения Яндекса**. Такие файлы помечаются `failed` (диск) или `skipped` (безлимит) с причиной. Когда Яндекс починит серверы, их можно добрать:

```bash
python main.py retry-failed                        # диск: failed → pending → скачивание
python unlim_backup.py --target skipped --media all --out-dir "ПУТЬ" --workers 4
```

Не запускай массовый сброс ошибок, если Яндекс ещё не восстановил шарды — мёртвые файлы вернутся в очередь и замедлят выгрузку.

### Потоки безлимита «висят» на одном файле

Мёртвый шард может отдавать байты очень медленно, не вызывая таймаут. В `unlim_backup.py` есть предохранитель: на каждый файл отводится `max(120, --timeout * 60)` секунд (по умолчанию ~420 с), после чего файл помечается `skipped`, а поток освобождается.

### Яндекс блокирует на 429 (Too Many Requests)

- Снизь `MAX_WORKERS` до 2-3
- Подожди 10-15 минут и попробуй снова
- Программа сама делает паузы при 429

### Указал DOWNLOAD_DIR=C:\ и сервер виснет

Программа защищена от этого — не обходит корни дисков. Укажи конкретную подпапку, например `C:/YandexBackup`.

### Безопасно ли использовать?

- ✅ **Токен и куки** хранятся только локально на твоём диске (`.env` и `cookies.json`)
- ✅ Эти файлы в `.gitignore` — не попадут в git
- ✅ Web-UI слушает только `127.0.0.1` — недоступен из интернета
- ✅ CSRF-защита: чужой сайт не сможет дёрнуть API
- ✅ Path traversal: нельзя сортировать системные папки (`C:/Windows` и т.д.)
- ⚠️ Безлимит через куки — серая зона по ToS Яндекса. Используй **только для своих данных** перед отменой подписки
