      Отдельные снимки помечаются, когда серверы Яндекса их не отдают: вместо пустого

      Рекомендуем оставить на диске C: превью занимают копейки, а базы
      и папки выгрузки на внешних дисках вы меняете — превью останутся на месте.

      Внутри — две простые папки: disk для Диска и unlim

      оригинал догрузится.

♻ Сброс очереди

    
Возвращает файлы из «отложенных», «ждут Яндекса», «ошибочных», «пропущенных» и «зависших» обратно в очередь. Меняются только статусы в базе — скачанные файлы не удаляются. Пока идёт выгрузка, сброс недоступен.

    

      
      
      
      
    

  


  

    
Базы данных

    
Пересоздание и переезд на другую папку. Всё применяется к выбранной базе.


    

      
      
      —
    


    

      ⚠️ Пересоздание удаляет базу и собирает её из облака заново. Последствия:
      

      • — скачанных и — сбойных
      файлов станут «в очереди» — статусы и история ошибок пропадут;
      

      • сами файлы на диске не удаляются;
      

      • программа ищет скачанное только по исходному пути «папка выгрузки / имя файла».
      Если сортировка уже применялась, файлы лежат в подпапках «Фото/…», «Видео/…» —
      они не найдутся и будут скачаны заново (для переезда есть
      «Перепривязать базу» ниже);
      

      • копия текущей базы сохраняется рядом с ней до начала работы.
    


    

      Сначала остановите выгрузку на главной — иначе кнопки не сработают.

Файлы переехали?

    

      Укажите папку, где сейчас лежат скачанные файлы. Программа сверит базу с диском,
      найдёт файлы в подпапках после сортировки и перепривяжет пути. Ничего не скачивается
      и не удаляется.
    


    

      
      
      
    

    

      
      
    

    

      Если файлы переезжали с одного диска на другой, укажите старую папку —
      перепривяжутся только записи из неё. Например, C:\NeUnlim → D:\NeUnlim
      или C:\Unlim → D:\Unlim; остальные пути не тронутся.
    

    


    

      
      
      
    


    

    

      

      

        
        
      

      

    


    

      

      

        
        
      

    


    

      «Вернуть структуру облака» пригодится, если папку Диска уже сортировали:
      файлы разложатся обратно по облачным папкам. Для Безлимита эта кнопка не нужна —
      там сортировка по датам и есть основная раскладка.
