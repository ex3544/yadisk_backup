Отдельные снимки помечаются, когда серверы Яндекса их не отдают: вместо пустого места лежит маленькая копия, а оригинал остаётся в очереди.

Что это и как получить куки

Яндекс прячет фото с телефона в скрытом хранилище — через REST API оно не отдаётся, нужны куки браузера.

  1. Установите расширение Cookie-Editor
  2. Откройте disk.yandex.ru и войдите в аккаунт
  3. Нажмите на иконку Cookie-Editor → Export → Export as JSON
  4. Вставьте JSON ниже → «Проверить» → потом «Сохранить»
Куки сохраняются только локально, в git не попадают.

♻ Сброс очереди

    
Возвращает файлы из «ошибочных», «пропущенных» и «зависших» обратно в очередь. Меняются только статусы в базе — скачанные файлы не удаляются. Пока идёт выгрузка, сброс недоступен.

    

      
      
      
    

  


  

    
Базы данных

    
Пересоздание и переезд на другую папку. Всё применяется к выбранной базе.


    

      
      
      —
    


    

      ⚠️ Пересоздание удаляет базу и собирает её из облака заново. Последствия:
      

      • — скачанных и — сбойных
      файлов станут «в очереди» — статусы и история ошибок пропадут;
      

      • сами файлы на диске не удаляются;
      

      • программа ищет скачанное только по исходному пути «папка выгрузки / имя файла».
      Если сортировка уже применялась, файлы лежат в подпапках «Фото/…», «Видео/…» —
      они не найдутся и будут скачаны заново (для переезда есть
      «Перепривязать базу» ниже);
      

      • копия текущей базы сохраняется рядом с ней до начала работы.
    


    

      Сначала остановите выгрузку на главной — иначе кнопки не сработают.
    

    
    

      
      
    


    


    
Переезд на другую папку

    
Для случая, когда файлы уже перенесены на новый диск. Сам перенос программа не делает.

    
    

      
      
    

    

      
      
    

    

      «Перепривязать» только меняет пути в базе — ничего не скачивается.
      «Скачать заново» возвращает всё в очередь и начинает выгрузку в новую папку; копия базы сохраняется.
    

    

  


  

    
Обновления

    
Проверка последнего релиза и обновление прямо из программы. Установщик скачивается с GitHub, сверяется SHA-256 и запускается после закрытия приложения.

      Программа закроется, установит новую версию и снова откроется. Права
      администратора не нужны. Настройки и скачанные файлы не удаляются.
