Что это и как получить куки

Яндекс прячет фото с телефона в скрытом хранилище — через REST API оно не отдаётся, нужны куки браузера.

  1. Установи расширение Cookie-Editor
  2. Открой disk.yandex.ru и залогинься
  3. Кликни на иконку Cookie-Editor → Export → Export as JSON
  4. Вставь JSON ниже → «Проверить» → потом «Сохранить»
Куки сохраняются только локально, в git не попадают.

Пересоздание базы Безлимита

    
Крайняя мера. Нужна, только если база повреждена и «Сформировать базу данных» не помогает.


    

      ⚠️ База удаляется и собирается из облака заново. Последствия:
      

      • — скачанных и — пропущенных
      файлов снова станут «в очереди» — их статусы и история ошибок пропадут;
      

      • сами файлы на диске не удаляются;
      

      • программа ищет скачанное только по исходному пути «папка загрузки / имя файла».
      Если сортировка уже применялась, файлы лежат в подпапках «Фото/…», «Видео/…» —
      они не найдутся и будут скачаны заново;
      

      • копия текущей базы сохраняется автоматически рядом с ней до начала работы.
    


    

      Сначала остановите скачивание Безлимита на главной — иначе кнопка не сработает.
